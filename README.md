# self-introduction-practice

## 概要

COACHTECH 教材 Tutorial 5-1「HTMLの基礎 ハンズオン演習」で作成した成果物です。
簡単な自己紹介をHTMLで作成しました。

## 使用技術

- HTML5
まだHTMLしか使えないので、これから理解を深めていければと思います。

## 学んだこと

<!DOCTYPE><html><head><body>と言った基本の部分は高校時代に教えてもらったこともあり、難なく使うことが出来ました。

リンクや画像の挿入もわかっていたのですが、作ったことのない問い合わせフォームに苦戦しました。

<form><label><select><textarea><botton>などはこの課題で初めて使い方を知りました。
ホームページなどでよく見る問い合わせフォームはこうしたコードから出来ているんだなと勉強になりました。
特に<lavel>の使い方がわからず、AIに相談しながら入れる場所を考えました。
まだ使いこなすまでには至っていませんが、実践を積んで慣れていけたらと思っています。
この短い自己紹介や、フォームを作るためにもたくさんのコードと知識が必要なんだなと改めて感じました。

## 動作確認

コードを書きながら気になるところはブラウザを開いて確認しつつ作業をしました。
